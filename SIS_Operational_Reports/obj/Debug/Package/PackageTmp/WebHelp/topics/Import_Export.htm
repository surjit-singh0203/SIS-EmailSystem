Import/Export

 

a)   Exporting Data to the Vessel:

To export the data to vessel, click on “Administration” on Navigation bar and click on “Import/Export” by selecting the Vessel Name for which the data is to be exported and Charter party start and end dates.

This will generate an MS Excel file, which you can export as an attachment on the designated ship’s email id.

b)   Importing Data from the Vessel:

To import data file from the Vessel, Choose the file from the local computer and click on “Import” to import the data from vessel to your software.
