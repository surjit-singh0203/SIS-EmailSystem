User Management Vessel

To access this page, click on “Administration” on the Navigation page and click on “User Management Vessel”. Here you can Add a new User for the vessel or edit/delete other users.

 

 

 To add a new user, click on “Add User” and fill in the details. Click on Submit to submit the details.

 

 

a)       User Role*: It refers to a role defined by the company for a particular User. Each role will have specific permission of access in the software.

For Master- All features of the software are accessible.

For Chief Officer- Rights are given only for adding/editing the Cargo part & Header part of any report.

For Chief Engineer- Rights are given only for adding/editing the Engineer part & Header part of any report.

For Second Officer- Rights are given only for adding/editing the Navigation & Header part of any report.

b)      User Email*: It refers to the email ID assigned by the office.

c)       Password*: It refers to the password assigned by the office.

d)      Confirm Password*: It refers to duplicating password added in the above field.

e)      Assign Vessel*: It refers to a user assigned for a particular vessel by the office.
